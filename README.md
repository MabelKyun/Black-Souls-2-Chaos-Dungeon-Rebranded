# Black-Souls-2-Chaos-Dungeon-Rebranded
A cool and definitely necessary mod for Black Souls 2 that attempts to alleviate the boredom one would get while grinding Chaos Dungeon by adding over 50+ new bosses to keep things fresh. New bosses and regular enemies will come with each new update. 

Installation: Simply download the files and then copy them into your BS2 folder and replace them. Make sure to make a backup of the original files if you need to uninstall the mod. Mod created without any compatibilities in mind, so if another mod modifies the Chaos Dungeon, it will most likely be incompatible.
